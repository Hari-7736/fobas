# Fobas website: React + Node.js API + Supabase, hosted on Vercel
See the deployment steps in the chat reply. Quick local run:
1. Create a Supabase project and run supabase/schema.sql in its SQL Editor.
2. Copy .env.example to .env and fill in the values.
3. npm install, then npm run dev. Site: http://localhost:5173  Admin: http://localhost:5173/admin
